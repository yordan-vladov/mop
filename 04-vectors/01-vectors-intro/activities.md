## 7. Работа с Python (numpy)

### Задача Ж

Прогнозирайте какво ще изведе всеки фрагмент, **преди** да го изпълните, след което проверете сами в Python.

```python
import numpy as np

a = np.array([3, 4])
b = np.array([1, 2])

# 1.
print(a + b)

# 2.
print(a - b)

# 3.
print(2 * a)

# 4.
print(np.linalg.norm(a))

# 5.
print(np.dot(a, b))

# 6.
print(a @ b)

# 7.
print(a / np.linalg.norm(a))
```

### Задача З — скорост на обект в игра

В 2D игра позицията на герой се променя всяка "рамка" (frame) чрез добавяне на вектор на скоростта към текущата му позиция.

```python
position = np.array([10, 20])
velocity = np.array([2, -1])
```

Напишете код на Python, който:

1. Пресмята новата позиция на героя след 5 "рамки" (т.е. `position + 5 * velocity`).
2. Пресмята скоростта на движение (дължината на вектора `velocity`) — колко "единици разстояние" се изминават за една рамка.
3. Създава нормализиран вектор `direction`, показващ **посоката** на движение (без значение от скоростта), и обяснява защо е полезно посоката и скоростта да се пазят отделно.

### Задача И — сходство между вектори (косинусово сходство)

Напишете код на Python, който:

1. Пресмята косинуса на ъгъла между `product1` и `product2`.
2. Пресмята косинуса на ъгъла между `product1` и `product3`.
3. Въз основа на резултатите, кой от двата продукта (`product2` или `product3`) е "по-сходен по посока" с `product1`? Съответства ли това на интуицията ви за приликата между продуктите?

### Задача К — проверка за перпендикулярност

Напишете функция на Python `are_perpendicular(v1, v2)`, която приема два вектора (`numpy` масива) и връща `True`, ако са перпендикулярни (скаларното им произведение е равно на 0, като се допуска малка грешка заради закръгляне, например с `np.isclose`), и `False` в противен случай. Тествайте функцията с:

