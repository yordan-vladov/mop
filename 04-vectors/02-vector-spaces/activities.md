1. Обяснете с думи защо множеството от всички 2D вектори $(x, y)$ с **положителни** координати ($x > 0$ и $y > 0$) **не** е векторно пространство. (Помислете кои аксиоми от таблицата в раздел 1 на урока се нарушават.)

## 7. Работа с Python (numpy)

Прогнозирайте какво ще изведе всеки фрагмент, **преди** да го изпълните, след което проверете сами в Python.

```python
import numpy as np

a = np.array([2, 5])
b = np.array([4, 10])

# 1.
A = np.array([a, b])
print(np.linalg.det(A))

# 2.

print(S @ v)

# 3.

print(Reflect_y @ v)

# 4.

Rot = np.array([[np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)]])
print(np.round(Rot @ v))
```
