## 7. Работа с Python

### Задача Ж

Прогнозирайте какво ще изведе всеки фрагмент, **преди** да го изпълните, след което проверете сами в Python.

```python
import math
from itertools import permutations, combinations

# 1.
print(math.factorial(4))

# 2.
print(math.perm(6, 2))

# 3.
print(math.comb(6, 2))

# 4.
print(len(list(permutations(['a', 'b', 'c', 'd'], 2))))

# 5.
print(len(list(combinations(['a', 'b', 'c', 'd'], 2))))

# 6.
print(math.perm(6, 2) // math.factorial(2) == math.comb(6, 2))
```
