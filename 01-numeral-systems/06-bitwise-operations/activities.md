## 5. Работа с Python

### Задача Г

Прогнозирайте какво ще изведе всеки от следните фрагменти, **преди** да ги изпълните, след което проверете сами в Python.

```python
# 1.
print(6 & 3)

# 2.
print(6 | 3)

# 3.
print(6 ^ 3)

# 4.
print(~6)

# 5.
print(5 << 2)

# 6.
print(20 >> 2)

# 7.
print(bin(13))
```

### Задача Д – проверка на бит

Напишете функция `is_bit_set(n, k)`, която връща `True`, ако бит номер `k` на `n` е вдигнат на `1`, и `False` в противен случай (както в урока). Тествайте я върху `n = 0b10110` за `k = 0, 1, 2, 4`.

### Задача Е – задаване, изчистване, превключване

Напишете трите функции `set_bit(n, k)`, `clear_bit(n, k)` и `toggle_bit(n, k)` (както в урока) и проверете резултата от всяка от тях чрез `bin(...)` върху `n = 0b1010`.

### Задача Ж – четност чрез побитова операция

Напишете функция `is_even(n)`, която проверява дали цялото число `n` е четно, използвайки **само** побитова операция (не `%`). Тествайте я за `n = 0, 1, 2, 17, 100`.

### Задача З – флагове

Дефинирайте трите флага `READ = 1 << 0`, `WRITE = 1 << 1`, `EXECUTE = 1 << 2`. Създайте променлива `permissions`, съдържаща само права за четене и изпълнение (без запис), след което:

1. Проверете с побитова операция дали `permissions` включва право за запис.
2. Добавете право за запис към `permissions` с побитова операция.
3. Премахнете правото за изпълнение от `permissions` с побитова операция.
4. Отпечатайте крайния резултат в двоичен вид с `bin(...)`.
