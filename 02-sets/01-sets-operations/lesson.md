## 1. Какво е множество

**Множество** е съвкупност от различни, добре определени обекти, наречени **елементи** на множеството. "Добре определени" означава, че за всеки обект можем еднозначно да кажем дали принадлежи на множеството или не. Елементите на едно множество са **неподредени** и не се повтарят – множеството $\{1, 2, 3\}$ и множеството $\{3, 1, 2, 1\}$ са едно и също множество.

Множествата обикновено се бележат с главни латински букви ($A$, $B$, $C$, ...), а елементите им – с малки букви или директно със стойностите им.

### 1.1 Записване на множество

Има два основни начина да зададем множество:

**Чрез изброяване** на елементите му, оградени във фигурни скоби:

$$A = \{1, 2, 3, 4, 5\}$$
$$B = \{\text{"ябълка"}, \text{"круша"}, \text{"банан"}\}$$

**Чрез задаване на свойство**, което елементите трябва да удовлетворяват:

$$A = \{x \mid x \text{ е цяло число и } 1 \le x \le 5\}$$

Записът се чете "множеството от всички $x$, такива че $x$ е цяло число между 1 и 5" – вертикалната черта $\mid$ се чете "такива че".

### 1.2 Принадлежност

Записваме, че елементът $x$ принадлежи на множеството $A$, със символа $\in$: $x \in A$. Ако $x$ не принадлежи на $A$, пишем $x \notin A$.

**Пример:** за $A = \{1, 2, 3\}$ имаме $2 \in A$, но $5 \notin A$.

### 1.3 Мощност на множество

**Мощността** на едно множество е броят на елементите му и се бележи с $|A|$.

**Пример:** за $A = \{1, 2, 3, 4, 5\}$ имаме $|A| = 5$.

### 1.4 Празно и универсално множество

**Празното множество**, бележено с $\emptyset$ или $\{\}$, е множеството, което няма елементи: $|\emptyset| = 0$.

**Универсалното множество**, бележено с $U$, е множеството от всички обекти, които разглеждаме в конкретна задача (контекстът, в който работим). Например, ако разглеждаме делителите на числата от 1 до 20, можем да изберем $U = \{1, 2, \dots, 20\}$.

## 2. Отношения между множества

### 2.1 Подмножество

Множеството $A$ е **подмножество** на множеството $B$ (бележим $A \subseteq B$), ако всеки елемент на $A$ е и елемент на $B$.

$$A \subseteq B \iff \forall x\ (x \in A \Rightarrow x \in B)$$

**Пример:** ако $A = \{1, 2\}$ и $B = \{1, 2, 3, 4\}$, то $A \subseteq B$.

Ако $A \subseteq B$, но съществува поне един елемент на $B$, който не принадлежи на $A$ (т.е. $A \neq B$), казваме, че $A$ е **същинско подмножество** на $B$ и бележим $A \subset B$.

> Празното множество е подмножество на всяко множество: $\emptyset \subseteq A$ за всяко $A$. Всяко множество е подмножество на себе си: $A \subseteq A$.

### 2.2 Равенство на множества

Две множества $A$ и $B$ са **равни** ($A = B$) точно тогава, когато имат едни и същи елементи, независимо от реда на изброяване или повторения в записа:

$$A = B \iff A \subseteq B \text{ и } B \subseteq A$$

**Пример:** $\{1, 2, 3\} = \{3, 2, 1\} = \{1, 1, 2, 3, 3\}$.

### 2.3 Дизюнктни множества

Две множества са **дизюнктни**, ако нямат общи елементи – сечението им е празното множество (сечението дефинираме в раздел 3.2).

**Пример:** $\{1, 2, 3\}$ и $\{4, 5\}$ са дизюнктни.

## 3. Операции с множества

За всяка операция по-долу ще илюстрираме резултата с **диаграма на Вен** (кръговете представят множествата, а защрихованата област – резултата от операцията) и ще дадем пример с конкретни числови множества.

За примерите в тази секция нека:

$$A = \{1, 2, 3, 4, 5\}, \qquad B = \{4, 5, 6, 7\}$$

### 3.1 Обединение ($A \cup B$)

**Обединението** на $A$ и $B$ е множеството от всички елементи, които принадлежат **на поне едно** от двете множества.

$$A \cup B = \{x \mid x \in A \text{ или } x \in B\}$$

**Пример:** $A \cup B = \{1, 2, 3, 4, 5, 6, 7\}$ (общите елементи 4 и 5 се записват само веднъж).

```
 ┌────────────┐┌────────────┐
 │      A     ││      B     │
 │   ┌────────┼┼────────┐   │
 │   │████████││████████│   │
 │   │████████││████████│   │
 │   └────────┼┼────────┘   │
 └────────────┘└────────────┘
      (цялата защрихована площ от двата кръга)
```

### 3.2 Сечение ($A \cap B$)

**Сечението** на $A$ и $B$ е множеството от всички елементи, които принадлежат **едновременно и на двете** множества.

$$A \cap B = \{x \mid x \in A \text{ и } x \in B\}$$

**Пример:** $A \cap B = \{4, 5\}$.

```
 ┌────────────┐┌────────────┐
 │      A     ││      B     │
 │   ┌────────┼┼────────┐   │
 │   │        ││████████│   │
 │   │        ││████████│   │
 │   └────────┼┼────────┘   │
 └────────────┘└────────────┘
      (защрихована е само общата площ)
```

Ако $A \cap B = \emptyset$, множествата са дизюнктни (виж 2.3).

### 3.3 Разлика ($A \setminus B$)

**Разликата** $A \setminus B$ (чете се "A без B") е множеството от елементите на $A$, които **не** принадлежат на $B$.

$$A \setminus B = \{x \mid x \in A \text{ и } x \notin B\}$$

**Пример:** $A \setminus B = \{1, 2, 3\}$, а $B \setminus A = \{6, 7\}$.

> **Важно:** разликата **не е комутативна** – по общо правило $A \setminus B \neq B \setminus A$, за разлика от обединението и сечението.

```
 ┌────────────┐┌────────────┐
 │      A     ││      B     │
 │   ┌────────┼┼────────┐   │
 │███│        ││        │   │
 │███│        ││        │   │
 │   └────────┼┼────────┘   │
 └────────────┘└────────────┘
      (защрихована само частта на A извън B)
```

### 3.4 Симетрична разлика ($A \triangle B$)

**Симетричната разлика** е множеството от елементите, които принадлежат на точно едно от двете множества (но не и на двете едновременно):

$$A \triangle B = (A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$$

**Пример:** $A \triangle B = \{1, 2, 3\} \cup \{6, 7\} = \{1, 2, 3, 6, 7\}$.

```
 ┌────────────┐┌────────────┐
 │      A     ││      B     │
 │   ┌────────┼┼────────┐   │
 │███│        ││        │███│
 │███│        ││        │███│
 │   └────────┼┼────────┘   │
 └────────────┘└────────────┘
    (защрихована площ на A и B без общата им част)
```

### 3.5 Допълнение ($\overline{A}$ или $A^c$)

**Допълнението** на $A$ (спрямо избраното универсално множество $U$) е множеството от всички елементи на $U$, които не принадлежат на $A$:

$$\overline{A} = U \setminus A = \{x \mid x \in U \text{ и } x \notin A\}$$

**Пример:** ако $U = \{1, 2, \dots, 10\}$ и $A = \{1, 2, 3, 4, 5\}$, то $\overline{A} = \{6, 7, 8, 9, 10\}$.

> Допълнението винаги е спрямо конкретно избрано универсално множество – без да сме дефинирали $U$, изразът $\overline{A}$ е безсмислен.

## 4. Основни свойства (закони) на операциите с множества

Нека $A$, $B$, $C$ са произволни подмножества на универсалното множество $U$. В сила са следните закони (пряка аналогия с логическите закони за И/ИЛИ и с побитовите операции от предишната тема):

| Закон | Формулировка |
|---|---|
| Комутативност | $A \cup B = B \cup A$, $\quad A \cap B = B \cap A$ |
| Асоциативност | $(A \cup B) \cup C = A \cup (B \cup C)$, $\quad (A \cap B) \cap C = A \cap (B \cap C)$ |
| Дистрибутивност | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$, $\quad A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ |
| Идемпотентност | $A \cup A = A$, $\quad A \cap A = A$ |
| Закони на де Морган | $\overline{A \cup B} = \overline{A} \cap \overline{B}$, $\quad \overline{A \cap B} = \overline{A} \cup \overline{B}$ |
| Двойно допълнение | $\overline{\overline{A}} = A$ |
| С празно/универсално множество | $A \cup \emptyset = A$, $\ A \cap \emptyset = \emptyset$, $\ A \cup U = U$, $\ A \cap U = A$ |

**Формула за мощността на обединение** (принцип на включване-изключване за две множества):

$$|A \cup B| = |A| + |B| - |A \cap B|$$

Изваждаме $|A \cap B|$, защото общите елементи иначе биха се преброили два пъти – веднъж в $|A|$ и веднъж в $|B|$.

**Пример:** за $A = \{1,2,3,4,5\}$, $B = \{4,5,6,7\}$ имаме $|A| = 5$, $|B| = 4$, $|A \cap B| = 2$, следователно $|A \cup B| = 5 + 4 - 2 = 7$ ✓ (съвпада с директното преброяване от 3.1).

## 5. Множества в Python

Python има вграден тип `set`, който директно поддържа операциите с множества.

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7}

print(A | B)   # обединение     -> {1, 2, 3, 4, 5, 6, 7}
print(A & B)   # сечение        -> {4, 5}
print(A - B)   # разлика A \ B  -> {1, 2, 3}
print(B - A)   # разлика B \ A  -> {6, 7}
print(A ^ B)   # симетр. разлика -> {1, 2, 3, 6, 7}

print(len(A))            # мощност |A| -> 5
print(3 in A)             # принадлежност -> True
print({1, 2}.issubset(A)) # подмножество -> True
print(A.isdisjoint(B))    # дизюнктни ли са -> False
```

Забележете директното съответствие между математическите символи и Python операторите: $\cup \to$ `|`, $\cap \to$ `&`, $\setminus \to$ `-`, $\triangle \to$ `^`. Не е случайност, че тези символи съвпадат с побитовите оператори от предишния урок – и там, и тук `|`/`&` изразяват идеята "поне един"/"и двата" (само че веднъж върху битове, а веднъж върху елементи на множество).

## Обобщение

- **Множество** е съвкупност от различни, неподредени елементи; записва се чрез изброяване или чрез свойство. Мощността $|A|$ е броят на елементите му.
- $A \subseteq B$ означава, че всеки елемент на $A$ е и елемент на $B$; $A = B$ означава $A \subseteq B$ и $B \subseteq A$ едновременно.
- Петте основни операции: **обединение** ($\cup$, "или"), **сечение** ($\cap$, "и"), **разлика** ($\setminus$, елементи само на едното), **симетрична разлика** ($\triangle$, елементи само на едно от двете), **допълнение** ($\overline{A}$, спрямо избрано универсално множество $U$).
- Разликата **не е комутативна**: $A \setminus B \neq B \setminus A$ по общо правило.
- Валидни са закони, аналогични на логическите: комутативност, асоциативност, дистрибутивност, законите на де Морган.
- $|A \cup B| = |A| + |B| - |A \cap B|$ — принцип на включване-изключване за две множества.
- В Python типът `set` поддържа директно тези операции чрез операторите `|`, `&`, `-`, `^`.
