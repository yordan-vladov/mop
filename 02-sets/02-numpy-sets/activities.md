## 2. Операции с множества в NumPy

### Задача Б

Прогнозирайте какво ще изведе всеки фрагмент, **преди** да го изпълните, след което проверете сами в Python.

```python
import numpy as np

A = np.array([5, 1, 3, 3, 7, 9])
B = np.array([3, 4, 5, 5, 6])

# 1.
print(np.unique(A))

# 2.
print(np.union1d(A, B))

# 3.
print(np.intersect1d(A, B))

# 4.
print(np.setdiff1d(A, B))

# 5.
print(np.setdiff1d(B, A))

# 6.
print(np.setxor1d(A, B))

# 7.
print(np.isin(A, B))

# 8.
print(A[np.isin(A, B)])

# 9.
print(A[np.isin(A, B, invert=True)])

# 10.
print(np.unique(B).size)
```

### Задача В — проверка на равенства в NumPy

За масивите `A` и `B` от Задача Б напишете код, който проверява следните равенства, като пресмята двете страни поотделно:

1. $A \cup B = B \cup A$
2. $A \triangle B = (A \cup B) \setminus (A \cap B)$
3. $A \setminus B = A \setminus (A \cap B)$

За сравняване използвайте `np.array_equal(x, y)`, която връща едно булево значение — `True`, ако двата масива имат еднакъв размер и еднакви елементи.
