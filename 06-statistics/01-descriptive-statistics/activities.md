## 5. Python: капанът с `ddof`

### Задача Д

Даден е следният код на Python. **Преди** да го изпълните, запишете какво очаквате да изведе всеки `print`, след което проверете сами:

```python
import statistics as st
import numpy as np

data = [10, 12, 14, 16, 18]

print(st.pstdev(data))
print(st.stdev(data))

print(np.std(data))
print(np.std(data, ddof=1))
```

1. Кои от четирите резултата очаквате да бъдат равни едно на друго?
2. Кои два реда пресмятат стандартно отклонение за "генерална съвкупност", и кои два — за "извадка"?
3. Ако някой напише `np.std(data)`, очаквайки резултат за извадка, каква грешка (концептуална, не синтактична) прави?
