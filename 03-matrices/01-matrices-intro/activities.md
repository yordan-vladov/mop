## 5. Матрично умножение "на ръка"

### Задача Е

### Задача Ж

## 7. Работа с Python (numpy)

### Задача И

Прогнозирайте какво ще изведе всеки фрагмент, **преди** да го изпълните, след което проверете сами в Python.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[2, 0], [1, 2]])

# 1.
print(A + B)

# 2.
print(A - B)

# 3.
print(2 * A)

# 4.
print(A * B)

# 5.
print(A @ B)

# 6.
print(A.T)

# 7.
print(A.shape)
```
